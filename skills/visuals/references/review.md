# Review the result

Check two independent questions:
- Meaning: does the picture preserve the actual actors, data, ordering, units, failure paths and evidence level?
- Presentation: can the intended reader see labels, controls, grouping and changes at the delivered size?

For interaction, exercise the meaningful states, keyboard access, replay and fallback. For video,
inspect the exported file rather than assuming the preview and encoder agree. Save review notes
in the existing design record only when they support a decision; do not create a review database.

For a substantial uncertain design, give an independent reviewer the artifact, raw requirement
and evidence, not the author's preferred conclusion. Fix concrete defects; don't add review
rounds for settled styling preferences. Clearly label a self-check as a self-check.

Use representative examples and adjacent non-triggers to evaluate the skill itself. A request
to draw a race should get a sequence; a one-line typo fix should not get a diagram; a game-feel
spike should not be declared fun from static checks. Static link tests are not agent trials.
